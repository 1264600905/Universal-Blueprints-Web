# 蓝图导出详细指南

本指南按照导出窗口从上到下的顺序，为你解释每一个功能选项。

---

## 一、 顶部工具栏 (配置与自动化)

在窗口最上方，有一排用于管理输入状态和翻译的按钮：

1. **启用暂存**：勾选后，即使你关闭窗口，已填写的内容也会被保留。点击“重置内容”可清空。
2. **语言切换**：点击切换当前正在编辑的语言版本。你可以为不同语言编写特定的名称和描述。
3. **自动翻译**：点击后，AI 会根据当前填写的文字，自动填充其他所有语言的翻译。
4. **翻译配置**：设置 AI 翻译所需的 API Key 和模型地址。

---

## 二、 核心信息区域 (必填与选填)

这是蓝图的基础身份标识：

### 1. 建筑名称 (必填)
- **说明**：决定了保存的文件名。
- **限制**：不能包含 `< > : " / \ | ? *`。
- **校验**：输入框下方会实时显示“名称有效”或报错。

### 2. 描述 (可选)
- **说明**：详细介绍建筑的功能或背景。支持多行输入。

### 3. 作者 (可选)
- **限制**：**不能包含空格**或特殊符号（如 `@ # $ %`）,不能以数字开头。
- **建议**：使用英文或拼音，例如 `Artisan_Li`。

### 4. 导出区域
- **下拉菜单**：默认为“框选矩形区域”。
- **活动区导出**：如果你在地图上设置了“活动区”,且活动区至少有一格，可以在此处选择对应的活动区名称。

![活动区选择](ExportAreaSelection)

你可以新建一个活动区，然后使用添加活动区，覆盖你希望导出的建筑范围。

![添加活动区](AddExportArea)

然后在这里选择此活动区，并且导出，即可实现不规则导出，只导出了你选择的部分。
活动区导出可以极大的减少必要的建筑内容被写入，可以让蓝图更加干净，精准。
同时活动区导出时因为框选区域不再是导出区域，你可以自由的选择一个更好的截图区域。

![活动区导出案例](ExportAreaExample)

比如这张蓝图虽然框选部分，很大，但是实际上大小是**,蓝图的最终大小还是根据你的活动区来的。
如果是一张超大的基地蓝图，可以通过划分不同的导出区域，以此拆分蓝图大小，减轻放置时的卡顿。

### 5. 类别 (必填)
- **默认模式**：点击“选择类别”按钮，从预设列表中选择最接近的一个。

![类别选择](CategorySelection)

- **自定义模式**：勾选底部的“使用自定义类别功能”后，此框变为可输入状态。**注意：自定义类别名也不能有空格。**

![自定义类别勾选](CustomCategoryCheckbox)

自定义类别导出的建筑，会单独分类显示。

![自定义分类显示](CustomCategoryDisplay)

你可以自己出一个系列蓝图，然后使用同一个自定义类别名称，最终它们会显示到一起。

![系列蓝图显示](SeriesBlueprintDisplay)

在远程蓝图内部，自定义分类也可以被选中。

![远程蓝图分类](RemoteBlueprintCategory)

让玩家更快找到你的蓝图.

## 三、 高级功能卡片 (按需开启)

只有在底部勾选了对应选项后，这些卡片才会显示：

### 1. 分组信息 (Fold Group)
- **分组名称**：相同分组名称的蓝图会在库中被折叠在一起。

![折叠效果](FoldGroupExample)

- **显示顺序**：数字越小，在折叠列表里排得越靠前。

![排名效果](FoldGroupRanking)

- **设置封面**：一个分组里只能有一个蓝图作为封面。
此功能的设计意图是让玩家可以出一些分阶段蓝图，比如一个基地的各个阶段的蓝图，让它们合并显示,方便查看。

### 2. 关联 URL
- **URL 名称**：例如“视频演示”或“作者主页”。

![URL输入](UrlInputLocation)

- **URL 地址**：仅支持 BiliBili、YouTube、小黑盒等白名单域名。

![URL效果](UrlFinalEffect)

### 3. 自定义建筑 ID
- **用途**：如果你要**更新替换**云端已有的蓝图，请填入那个蓝图的原 ID。否则请保持为空。

![建筑ID输入](BuildingIDInput)

注意更新蓝图会存在3到五分钟延迟，且需要你重启游戏才能真正看到修改效果。
---

### 3. 导出全部物品 (备份导出) —— **重要！**
这是区分“标准版”和“完整版”蓝图的关键开关：

![全部导出](ExportAllItemsCheckbox)

- **不勾选 (标准分享模式)**：
    - **包含**：建筑、人工地板、电缆、水管，灯，屋顶区。
    - **不含**：泥土/沙子等自然地形、地上的资源、植物、小人、动物。
    - **特点**：文件小，兼容性强，适合分享设计。

- **勾选 (备份/搬家模式)**：
    - **包含**：所有东西！包括自然地形、地上的每一块木头、植物、
    甚至殖民者及其装备（需 Character Editor 模组）,
    存储建筑的筛选,工作台的制作配方,存储区（需要[KV] Save Storage, Outfit, Crafting, Dr）。
    - **特点**：紫色角标显示。文件大，依赖多，适合自己搬家或存档备份。

## 五、 执行框选
   注意框选的截图完全基于屏幕坐标，你点击的左上角和右下角决定了截图的范围，如果在截图过程中移动镜头，截图范围是不会变化的，永远是你点击的屏幕位置，而不是游戏地图的世界坐标！

## 六、 模组报告

如果你希望知道布局内物品归属于哪个模组，可以使用模组报告功能。

![显示模组报告按钮](ModReportBtn)

点击后框选需要检查模组的区域。

![框选模组报告区域](ModReportSelectArea)

在模组报告页面，可以看到区域存在的模组内容。

![模组报告详情](ModReportDetails)

其中 **显示** 可以高亮模组建筑格子，如果可以选中，那么会选中这些物品。**删除** 按钮点击后会直接为你删除这些物品。

![模组报告高亮显示](ModReportHighlight)

而 **替换** 表示你可以从一个特定模组选择一个建筑去替换此建筑或者地板。其中 **高级选项** 指的是允许你选择旋转和材质，注意选择可能会直接覆盖其他建筑。

![模组报告替换页面](ModReportReplace)

这个功能意图在帮助蓝图制作者给蓝图降低模组依赖。
